# Tracks screen

- **Tracks** (`TracksView.vue` and its dialogs): indented past the navigation toggle as a whole, like Today; under 1024px only the header row is, and the lists use the full width with 12px side padding. One of the two screens that ask for archived tracks (`?includeArchived=true`), with Analytics. Active tracks as `NcListItem`s (drag handle, hidden on `@media (hover: none)` with the archived list's stand-in, where Move up/down in the ⋯ menu reorder; type line with the number of public links, "Yes/No · Private · 2 public links" (`trackSubname`), ⋯ menu: Show analytics, Rename track (opens the sidebar with the name being edited), Move up/down, Archive, Delete); dragging is Sortable.js through `useSortable` on the list, started only on the handle, with the row itself faded in place as the drop's preview (`.sortable-ghost`); its `onUpdate` puts the row back in the DOM and calls `move()`, so Vue renders the order and a refused save undoes it. Not a native `draggable` handle: `NcListItem` is a link, and Firefox drags the enclosing link instead ([`nsContentAreaDragDrop.cpp`](https://github.com/mozilla-firefox/firefox/blob/main/dom/base/nsContentAreaDragDrop.cpp), `DragDataProducer::Produce`, read 2026-11-28, takes the closest link as the drag node; Sortable's `ignore: 'a, img'` turns the link's `draggable` off). The row opens `NcAppSidebar` (`TrackSidebar.vue`: the name block drawn in the `info` slot, as the sidebar has no slot after the name, with the name as an `NcAppSidebarHeader` and a grey pencil-outline after it, either starting the edit (Enter or blur saves, Escape cancels), then the type; Private switch, then "Archive track" and "Delete track" as label-width buttons side by side, each opening the same confirm as the row's menu; no ⋯ menu in the sidebar). The sidebar has two tabs, Details (what is described above) and **Public links** (`PublicLinksTab.vue`, `PublicLinkRow.vue`); it opens on Details, keeps the tab shown when another track's sidebar replaces it, and starts on Details again after closing. The Public links tab is mounted each time it is shown (so it loads afresh and its form and "How to use public links" start closed): the help sentence, the links oldest first (a round link icon, name, "Tick only · +1 day", "Last used …", a copy button, which shows a tick and "Link copied" for 4 seconds after a copy, as Files', and a ⋯ menu with Rename and Revoke), or a dashed "No public links yet" box (not `NcEmptyContent`, too large there), "New public link", which replaces the list with the create form in place (name, Permissions as two plain radios as New track's Type, Allowed days as an `NcSelect`; Tick only and +1 day to start with; Create copies the new link), and the "How to use public links" disclosure, shown with or without links, whose commands show this server's address up to `/ping/` (from the first link's `url`, else `generateOcsUrl`) and `…` for the token: **no token is ever shown on screen**, only copied (`navigator.clipboard`, which needs a secure context). Renaming a link leaves just the round icon and a name field, which works as the track's name: Enter or losing focus saves, Escape cancels, a blank or unchanged name isn't sent. A create or revoke emits `links-changed`, on which the page reloads its tracks for the count. Archived tracks go in a collapsed "Archived tracks (n)" list under it, alphabetical, drawn by hand in `NcListItem`'s column (an empty space the drag handle's width, the ⋯ in the same place; `NcListItem` is always a link), with "Show analytics" (the only way into an archived track's Analytics), "Restore track" (no confirm, to the end of the list) and "Delete track" in a ⋯ menu; every row of both lists has a 1px `--color-border` line under it. The archived list is hidden when nothing is archived, collapsed on every load, opened after every successful archive. The delete confirm for an active track offers "Archive instead" (no second confirm), via the dialog's `actions` slot. Both the archive and the delete confirm add "This track's 2 public links will be revoked." (`archiveLinksText`) when the track has links. New track (`NewTrackDialog.vue`) creates with `POST /api/tracks`, then makes it private with a second `PUT` (the server takes no `private` on create; adding it would change the create's `Idempotency-Key` fingerprint). Import and Export are dialogs from the header's menu, whose trigger shows MDI's `file-swap-outline` ("Import and export") so it stands apart from the rows' ⋯. `TracksView` renders its own `NcAppContent` with the sidebar beside it; the other screens sit in `App.vue`'s.
